## Как мы пришли на степик

* Автор курса "Си для начинающих", МФТИ (вставить актуальную статистику ближе к выступлению и QR код ссылки на курс).
* До курса: задачи в системе Ejudge (движок для проведения олимпиад) + теория в TWiki, есть скрипты.
    * Надо в цикле: 
        * теория
        * контрольные вопросы
        * задачи на программирование 
    * Фактически:
        * Ejudge - высокий порог вхождения (xml + ssh), молодые преподаватели не вовлечены.
        * Ejudge - xml не предназначен для людей, в нем трудно редактировать и создавать задачу (валидация, недостаточная документация схемы).
        * Ejudge - только появились типы для контрольных вопросов, мало.
        * Нет переключения: сначала вся теория, потом все задачи.
        
* Альтернативы:
    * Coursera - не работает с физлицами, долгий процесс подготовки курса (не дружит с Россией)
    * Открытое образование и тп. - нет объекта "задача на программирование с автоматическим прогоном тестов"
    * moodle (lms.mipt.ru)
        * убогий внешний вид для небольшого экрана ноутбука (скриншоты)
        * мобильное приложение (русский язык, сайт должен быть специально настроен, баги)
        * (сайт МФТИ) сопряжение с 1С института - есть студенты, нельзя зарегистрироваться абитуриентам и школьникам
        * проблема с автоматизацией деплоя
    * stepik:
        * работает с авторами-физиками, можно бесплатно.
        * эргономичный внешний вид
        * мобильное приложение
        * широкая аудитория, любой может зарегистрироваться и проходить курс
        
## Проблемы работы на степике

Степик создал удобный интерфейс для учеников, но к интерфейсу для авторов и учителей есть вопросы.

    * Работа на небольшом экране ноутбука - непрерывный скролл, особенно в задачах. Не видно все тесты.
    * Нет функциональности "из коробки", к которой привыкли на Ejudge
        * удобный вид диагностики учащемуся о проблеме в тесте в задаче  на программирование
        * к каждой задаче надо написать свой чекер
        * отсутствие стандартных чекеров (`cmp_seq_int`, `cmp_seq_float`, `cmp_seq_long_long`, ...)
        * если выбрали язык python (и написали в ограничениях), то при выходе новой версии надо пройти по всем задачам и заменить/добавить версию. 
            * Меняли gcc на gcc + valgrind.
            * Изменить подсказки во всех вопросах модуля - тоже руками.
        * открытые тестовые данные (спасибо Поколению за раздел Тестовые данные, показать картинкой)
    * Пошаговое редактирование неудобно. Забыл где описал теорию - до этого шага или после. Поиск по курсу.
    * Разбить модуль номер 4 из 17 на три модуля. 5 минут обсуждения, 30+ минут технической реализации через GUI
    * Совместная работа с соавтором - нажал Сохранить и перетёр правки. Сидим, восстанавливаем.
    * Нет интернета - нет работы. Дача, глушат мобильный интернет, в дороге.

## Решаем проблемы

Решение большинства проблем - редактирование и хранение в текстовом формате + деплой на сайт скриптами на основе API степика.

    * Формат - измененный markdown: форматирование, матформулы + разметка для типов шагов.
    * Хранение содержимого курса в системе контроля версий (курсы на гитхабе)
        * бэкап
        * версионность
        * совместная работа (тут немного рассказать для авторов-гуманитариев git commit, git log, git blame и ветки, 1-2 картинки)
        * переносимость
        * комментарии, дискуссии, список багов и что сделать с приоритетами (github)
    * Редактирование курса в разных оффлайн-редакторах (Notepad++, VSCode, Pycharm ...)
    * Python: легкая установка и использование из командной строки, платформонезависимо (Windows, Linux, etc)

## Деплой урока и шага

1 урок в 1 файле. Например, это `3_2_boolean.md` 

`python deploy.py FILE [-s step_position]

* Создаем урок руками в степиковском редакторе, записываем id урока, показываю откуда его брать

* Деплой урока:
`python deploy.py 3_2_boolean.md`
    * изменить существующие шаги урока
    * удалить лишние шаги в конце
    * добавить недостающие в конце
    
* Изменение шага:
`python deploy.py 3_2_boolean.md -s 4` (показать откуда берем позицию)
`python deploy.py 3_2_boolean.md -s -1` (последний шаг)

* Проблема - вставка нового шага в середину
    * нужно сохранить комментарии и решения
    * создаем шаг любого типа (например, текст), передвигаем на нужное место
    * запускаем скрипт на апдейт урока или только нового шага.

## toc - Table of Content - Содержание (надеемся доработать до конференции)

* Содержимое курса `toc.yaml`
```yaml
course: название курса для человека
course_id: 57680
modules:
    - name: "Введение"
      number: 1
      module_id: 123456
      dir: 1_intro   # путь относительно этого файла
      lessons:
        - name: "Как учиться на курсе"
          id: 406086
          file: 1_1_howto_learn.md  # путь относительно dir модуля
          
        - name: Установка программ
          id: 406088
          file: 'C:\work\my_course\python_installation.md' # можно абсолютный путь

    - name: "Hello, world!"
      number: 2
      module_id: 123457
      dir: 2_hello
      lessons:
        - name: "Python как калькулятор"
          id:    # я еще не создала этот урок, только пишу его черновик
          file: 2_1_console.md
```          

Делаем один раз:
         
* `python deploy.py --toc --course_id 57680` - создать файл `toc_57680.yaml` с содержимым курса, где заполнены все поля, кроме `dir` и `file`. 


Делаем регулярно:

* `python deploy.py --toc 1.1` - деплой файла `1_1_howto_learn.md` 
`python deploy.py --toc 1.1.5` - деплой шага 5 файла `1_1_howto_learn.md`
